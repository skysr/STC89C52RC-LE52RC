# STC89C52RC-LE52RC

**AT89S52 单片机定时器应用示例程序说明**

---

### 一、功能概述
本程序基于 **AT89S52** 单片机（11.0592MHz 晶振），使用 **Timer2 16位自动重载模式** 实现精准定时，驱动 **LED** 周期性闪烁，并在 **QC1602A 液晶模块**（8位接口）上实时显示秒级计数器。

---

### 二、硬件配置
| 组件 | 连接端口 | 说明 |
|------|----------|------|
| LED 指示灯 | `P0^0` | 低电平点亮 |
| LCD 数据总线 | `P2` | D0~D7 8位并行数据 |
| LCD 控制脚 RS | `P0^1` | 寄存器选择（0:命令, 1:数据） |
| LCD 控制脚 EN | `P0^2` | 使能脉冲（高电平有效） |

---

### 三、定时器配置
- **Timer2 模式**：16位自动重载（`T2CON = 0x00`）
- **定时周期**：**50 ms**（重载值 `TH2=0x4C`, `TL2=0x00`）
- **中断频率**：每 50ms 触发一次 `timer2_isr()`
- **中断服务**：仅做标志位累加，**不执行耗时操作**，确保实时性

---

### 四、核心功能实现
1. **LED 闪烁**  
   - 中断计数器 `led_timer2_count` 每 50ms +1
   - 主循环判断 `>=10` 即 **500ms** 时翻转 LED 状态
   - **实际闪烁频率**：**1 Hz**（亮 500ms，灭 500ms）

2. **LCD 秒计数器**  
   - 中断计数器 `lcd_update_count_flag` 每 50ms +1
   - 主循环判断 `>=20` 即 **1秒** 时：
     - 全局变量 `lcd_update_count` 自增
     - 调用 `lcd_update_count_to_str()` 将数值转字符串（固定10位补零格式）
     - 在 LCD 第2行刷新显示

3. **LCD 初始化与显示**  
   - 8位模式初始化，显示开、光标关
   - 第1行固定标题：`LCD COUNT NUM:`
   - 第2行动态显示计数值：`0000000000` 起

---

### 五、代码特点与注意事项
- **中断轻量化**：中断服务程序仅累加计数器，所有 LCD 操作均在主循环中执行，避免中断阻塞
- **重复初始化问题**：`QC1602_Init8()` 在 `main()` 中被调用两次，第二次会清屏并覆盖初始内容，**建议删除第二次调用**
- **计数器范围**：`lcd_update_count` 为 `unsigned long` 类型，最大可计到 **4,294,967,295** 秒（约 136 年）
- **延时函数**：LCD 忙等待采用软件循环延时，精确度依赖晶振频率，如需更高精度可改用硬件定时器延时

---

### 六、性能参数
- **CPU 占用率**：中断服务约 **< 5 µs**，主循环轮询方式，总体占用极低
- **定时误差**：50ms 定时基于 11.0592MHz 晶振，理论误差 **0 ppm**
- **代码体积**：约 **1.2 KB**（Keil C51 编译，-O2 优化）

---

**适用场景**：学习 51 单片机定时器中断、LCD 驱动开发，或作为简单定时控制任务的模板。
